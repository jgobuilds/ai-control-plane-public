# AI Control Plane

A multi-agent orchestration framework: work enters through one router, disperses
into cost tiers and isolated lanes, and ships only through verified, human-gated
exits. n8n handles triggers and glue; a cost-tiering router dispatches to
firewalled runners that shell out to vendor CLIs, so model calls bill against
flat subscriptions rather than metered tokens.

## The rule that shapes every change

**This repo ships brand-neutral.** Real org identity — palettes, org names,
marketing pages — lives in a private overlay resolved generically at
`../<org>-instance` (or `$AICP_INSTANCE`), never here. The pre-commit guard
enforces it:

```bash
python scripts/check_public_hygiene.py            # staged files — the commit gate
python scripts/check_public_hygiene.py --tree     # every tracked file — the CI gate
```

Both modes matter. Staged-only scans nothing in CI, where nothing is ever
staged — it would pass while checking nothing.

## Design constraints

- **Deterministic before models.** The router tries rules first, then the
  cheapest capable tier. Don't reach for a model where a rule will do.
- **Human gates on irreversible acts** — merges, shipping, promotions,
  deletions. The gate is the product; removing one is a design change, not a
  refactor.
- **Every decision is appended to the audit ledger.** Don't add a path that
  acts without writing a record.
- **Runners are firewalled and talk only to their vendor.** The scrubber's PII
  vault is never mounted into a runner.
- Autonomy follows verification — see [`docs/design/LADDER.md`](docs/design/LADDER.md)
  for the rung-by-rung intent.

## Decisions get an ADR

Architectural choices go in `docs/decisions/` using
[`TEMPLATE.md`](docs/decisions/TEMPLATE.md), including a **Cost** column in the
options table. `scripts/adr_check.py` enforces the shape.

## Layout

| Path | What |
|---|---|
| `router/` | Cost tiering, scope + PII enforcement, dispatch |
| `claude-runner/`, `gemini-runner/` | Firewalled CLI runners, own auth volumes |
| `scrubber/` | PII tokenization; the vault lives here and nowhere else |
| `lanes/` | Scheduled Python lanes, driven by n8n over HTTP |
| `context/` | Scopes, policies, and the neutral `*.example` brand fallbacks |
| `workspace/` | The runtime context-scope tree (a product feature, not repo docs) |
| `scripts/` | Generators, gates, and operational tooling |

House engineering lenses are wired via `.engineering-standard/config.yml` to
`../ai-standards`. That path resolves on disk only — this file must carry
everything a contributor actually needs.
