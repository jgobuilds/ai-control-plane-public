# Enterprise scope (widest — inherited by every run)

Everything here is visible to ALL agents at every scope below. Only put content
that is safe and useful firm/company-wide:

- **Brand & voice**: naming, tone, style guide.
- **Frameworks & methodologies**: how we structure work, deliverable templates.
- **Approved tools**: which systems agents may use and how.
- **Universal rules**: security posture, "never include PII in outputs", etc.

Content reaches this level ONLY via the promotion gate (scrub → generalize →
human review). Never put tenant/customer names, numbers, or personal data here.
